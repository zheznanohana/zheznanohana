#### 游戏与 AI 系统 · Game Design & AI

- [**Xuwang-Director-1.7B**](https://github.com/zheznanohana/Xuwang-Director-1.7B) — 为卡牌战棋 SRPG《虚妄余罪》训练的本地 AI 导演模型。基于 `Qwen3-1.7B-Base` 做 LoRA 微调与蒸馏，用 193 个类型化决策头一次前向给出难度、遭遇、卡牌、Boss 战术、音乐等十类通道偏好；模型给倾向，本地规则负责约束与兜底。
- [**pi-chan · π娘**](https://github.com/zheznanohana/pi-chan) — 基于 Pi Coding Agent 的二次元 AI 伙伴。Live2D 看板娘与 Q 版桌宠陪你语音聊天，聊清想法后一键派发开发任务，把灵感接成原型。

#### 自己动手做的工具与底层实验 · Systems & Tools

*从需求，到可运行的代码。*

- [**nekodrop**](https://github.com/zheznanohana/nekodrop) — 直接用 Windows 笔记本自带的 Intel 无线网卡收发 AirDrop，同时保持正常 Wi-Fi 联网。
- [**attesor**](https://github.com/zheznanohana/attesor) — 「反向 Rosetta」：加载 `arm64` Mach-O 与 Apple Silicon 用户态缓存，通过解释器 + `x86-64` JIT、系统调用模拟与 Metal 桥接，在 Intel Mac 上运行 `arm64` macOS 应用。
- [**nekointelligence**](https://github.com/zheznanohana/nekointelligence) — 在 Intel Mac 上启用系统原生 Writing Tools，接入自己的 OpenAI 兼容模型接口。
- [**NekoCardReader**](https://github.com/zheznanohana/NekoCardReader) — 本地优先的中日交通卡（交通联合 / Suica / PASMO）读取、长期档案与通勤足迹地图可视化工具。
- [**nekolink**](https://github.com/zheznanohana/nekolink) · [**NekoHub**](https://github.com/zheznanohana/NekoHub) · [**echo-seed**](https://github.com/zheznanohana/echo-seed) — 跨设备 iPhone ANCS 蓝牙通知桥接、多端通知管理中心与个人想法胶囊记录工具。
